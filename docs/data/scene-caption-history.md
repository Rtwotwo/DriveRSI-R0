# 历史图像与自车状态联合标注

## 当前定位

Caption 用于场景检索和人工诊断。它不是驾驶失败原因、教师标签或训练准入证明。
本轮在 `exp/scene-caption-history-v8/` 保存真实输入、原始回答、失败和小样本审核。
本地 Qwen3.5-2B 的内容质量尚未通过全量发布，不能把 JSON 合法率当作事实准确率。

## 输入与来源

| 输入 | 保存方式 | 提供给 VLM 的内容 |
|---|---|---|
| 四条真实历史记录，每条三相机 | 12 张图及原文件哈希、实际时间、相机 ID | 每个调用只看一个相机的四张图；三个相机独立生成 |
| 自车历史状态 | 原生速度/加速度分量、锚点相对位置和航向、实际时间 | 带 ego_ 前缀的数值记录；不提供全局位置、token 或日志名 |
| 历史变化 | 代码计算速度差和首末航向差 | 作为自车事实保存，不能推出他车运动 |
| 道路或其他对象结构化事实 | 当前版本不送给 VLM | 后续若加入，单列为地图/标注事实，不冒充相机可见事实 |
| 评分、未来轨迹、未来图像 | 不输入标注器 | 仅在后续训练侧 Harness 决策时关联 |

不等间隔历史使用原始四条记录和实际时间；不补图，不改成名义 2 Hz，也不因此解除时序训练限制。
`driving_command` 编码未在本模块解释，避免误写导航语义。

## 输出契约

精确状态和视觉观察分开保存。模型不能改写测量值。每个相机输出五个短文本字段：

| 字段 | 含义 | 不应混入 |
|---|---|---|
| pavement | 当前画面车辆可通行地面的形状 | 顶棚、立柱等建筑形状 |
| road_paint | 可见的路面涂装；不清楚为 unknown | 路沿、路障、标牌、阴影；本试验不接受精细实虚线判断 |
| traffic_entities | 当前可见车辆/行人与图像内位置 | 速度、停车意图、让行、危险归因 |
| roadside_context | 能区分场景的环境、遮挡、路侧设施 | 商业名称转录、猜测天气 |
| image_change | 首末历史图的可见配置变化 | 将画面位移直接解释为物理运动 |

前四个字段由程序绑定当前 `h3_<camera>`；变化字段绑定 `h0` 与 `h3`。这些引用限定输入范围，
不证明描述是真的。模型不生成相机 ID，也不能引用其他相机。

完整状态、三个相机的全部原始文本和解析内容保留在数据库/raw 与可重建 sidecar 中。
供旧 FTS 接口使用的短 caption 交错取各相机完整字段，限制 1550 字符；不是完整描述的替代品。
现版本不凭自由文本自动编造 categorical tags。

## 已确认的问题

1. 老 v7 每个相机只读取当前帧，没有利用四帧自车状态。
2. 联合历史输入可运行，但 Qwen2B 仍会将建筑/立体物体当作道路要素，编造或误归因历史运动。
3. 开启模型思考没有在该小样本上解决问题；还出现将 ego 坐标套用到他车的情况及输出截断。
4. 因而新增硬性字段检查与输入前缀仅解决部分接口问题，不构成语义正确性的保证。

真实六日志试标注记录：初版解析 3 条通过、3 条拒绝；3 条格式通过记录复核后也被拒绝。
该样本多数来自 Las Vegas，并不是四城市随机质量估计。详情以 quality-review.json 为准。
旧回答重新检查单独记录；ego_ 前缀修订也重跑了一个真实样本，仍被路面类别混淆拒绝，不能称为质量已修复。

## 检索与分库

所有输入来源经 catalog 绑定。navtrain 与 navtest 使用各自数据库；当前提示词调试只用 navtrain。
新 history_state_v8 profile 的 lexical 检索及已有 hybrid 检索都要求逐条 `spot_check_pass`。
未审核和 rejected 原文可查但不会进入这些检索通道。不要给全量记录批量伪造人工通过标记。

向量库及其提取文件不改动。后续由向量/合格 caption/结构化事实召回训练来源，
再关联同版本模型的训练侧评分，确认弱点与同锚点原因。相似描述或低分都不能直接授权合成。
教师 PDMS≥95、物理执行、图像对应等准入继续由原有流程完成。

## 运行方式

继续使用 `driversi.data.catalog.labeling.label_batch`，配置
`src/config/data/scene_catalog/qwen35_history_v8.json`。产物写入 `exp/`。
成功记录复用时从数据库重建缺失 sidecar；同输入、同 profile 的已拒绝记录返回
`cached_rejected`，不花费相同推理重复生成同样错误。改变提示词/模型会形成新 profile。
输入缓存身份同时包含图像内容与精确历史状态。配置封存加载器、Pillow、pyquaternion 和模型版本。

全量多卡 caption 任务本轮未启动；现有多卡向量导出器不能直接当作多卡 caption 运行器。
下一步先在不同城市/道路/遮挡/标线样本上比较更可靠的标注配置，固定配置后再检验独立样本，
通过后建设有界多卡标注队列。小样本观察不能证明真实标注错误率为零。
