# DriveHarness 能力与实验 skill

DriveHarness 服务于驾驶模型的改进过程。这里的 skill 是有版本、前置条件、执行入口、预算和失败记录的实验程序，不是车辆执行的转弯/让行策略，也不是一段提示词。更换为 VLA 不会自动补齐实验归因或持续改进能力。

## 数据流

`navtest 聚合能力计数 → 条件假设 → navtrain 结构化/审核 caption/向量召回 → skill 选择 → 实际教师推演 → 独立准入 → 原生配对训练 → 评测及成本 → 经验记忆 → 下次选择`

测试图像、token、特征和轨迹不进入训练检索服务。能力计数通过既有严格汇总协议输入；使用测试反馈参与方法开发的实验仍标为 adaptive evaluation。它不等同于独立最终泛化验证。

## 不再依赖训练评分

`navsim_scene_expansion_plan` v2 使用 aggregate capability feedback；`navsim_scene_hybrid_retrieval` v2 使用训练侧 exemplar。两者均不接收 `score_run`，不读取学生评分表，不运行训练集推理。旧非空评分过滤配置明确拒绝。基础目录检索仅兼容旧的空评分字段。

条件到能力的对应是版本化假设。例如转向历史用于方向问题召回，并不表示这段训练日志逆行。向量 query 来自条件选中的 navtrain exemplar，不能将 Qwen 视觉特征当作文本对齐特征。按日志组去重与按能力轮转防止进度类占满预算。

caption 仅采用最新且人工抽查通过的记录；没有合格记录时该通道明确不启用，不用未经审核标签填补。检索结果叫“相关扩充候选”，不叫“已确认同原因失败”。

## 可执行 skill

当前 ChainFlow 可执行两种新历史策略：

- `reactive_new_history`：DriveZero 连续观察执行到新锚点，再调用原生教师生成未来。
- `bounded_perturbation_history`：受限控制扰动到达新锚点，再调用同一原生教师。

两者复用 `navsim_native_teacher_probe` 和 `native_branch_selection`，保留四帧新历史、十个真实未来点，以及现有 95 分和物理准入。规则背景不称为学习型多车自博弈。实际使用入口是 `scripts/rsi/run_capability_skill.py`；输入必须来自已封存的选择计划和官方训练来源。

`same_anchor_relabel` 保留作为服务定义，但尚未完成 ChainFlow 原生训练绑定，所以不向 ChainFlow 决策器提供。不能因为注册了一个 provider 就宣称任意模型可用。

## 经验记忆的边界

- 执行失败、准入失败和成功均记录真实耗时、场景身份及版本；失败不产生训练收益信用。
- 同一父模型下实际执行过的锚点不会在下一次选择中立即重复；准备失败可在修复后重试。背景接触标为世界有效性待诊断，不自动惩罚教师能力。
- 同父模型、同评测协议的配对收益才作为直接证据。跨父模型结果保留为单独列出的家族先验，不能伪装成当前模型收益。
- 混合多个能力/skill 的训练批次不能把总分提升分别归功于每个 skill；当前只给单一能力和配方的实验信用。
- 真实物理分支保存 skill 身份，训练编译检查该身份与原始训练成员一致。重复反馈幂等；新旧父权重、实际评测基准与协议不匹配则拒绝效果信用。
- 配对反馈入口再次检查实际训练样本的准入、物理分支和技能身份，不能绕过编译器把旧数据收益归给新计划。诊断复核使用追加记录，原证据保留，禁止修改原执行成本或创造收益。
- 已知训练/评测耗时与未知生成成本分开。缺少完整端到端成本时，不计算“单位总成本收益”。执行尝试的失败率和耗时仍可用于决定下一次探索。

这些是有约束的经验选择启发式，尚未证明改进器学会了稳定有效的策略，更不保证每轮驾驶指标上升。

## 配对训练接入

既有 `chainflow_round` 配置增加 `capability_plan` 和 `skill_memory` 即可在准入后绑定训练，并追加 `capability_skill_feedback` 阶段。两臂仍由同一原生训练器完成；loss、优化器和评分不修改。合成分支缺少实际 skill 执行身份时，不允许事后把历史训练归功于新计划。

LLM 只接受匿名训练条件、汇总能力与已有配方统计，只能从允许列表选择策略。凭据使用 `DRIVERSI_LLM_API_KEY` 环境变量；配置、产物、日志不得包含密钥。没有凭据时显式关闭，不能声称运行了模型辅助选择。

公司网关的模型标识按原样匹配：当前允许的是 `deepseek-v4-flash-0731`。不要自行改变大小写。截断或不完整 JSON 不能进入选择计划，错误日志仅记录终止状态与用量计数。示例配置只包含环境变量名；凭据通过运行环境注入，不存在于仓库。

## 当前实测范围

`exp/harness-capability-skills-v1` 的验收使用 24 个官方 navtrain token、24 个来源组。全库冷读取尚未完成性能验证，不能把这个小样本验收写成全库检索完成。生产库没有通过抽查的 caption，因此本轮实际召回使用结构化条件和已有向量，文本通道明确缺席。

真实 LLM 对三个匿名候选给出合法策略。实际执行了一条规则选择的 DriveRL 新历史和一条 LLM 选择的受限扰动，反事实 PDMS 为 100 和约 95.35，但均存在背景接触，保持 `trainable=false`。已追加原因和耗时，下一轮选择五个其他候选，没有重复这两个锚点。未启动新训练，也没有新的学生收益或改进器持续变强的证据。
