# AUGUstus 全量评测到 navval 训练闭环

当前生产路线要求 DriveRL 生成连续新历史及纠正未来，再执行同分支 GS、重新提取图像特征和分支语言监督。`continuation-policy.json` 已禁止自动退回原锚点重标注；旧 `scripts/rsi/run_navval_loop.py run ...` 不是本轮生产续接命令。

全量评测的跨节点执行入口：

```bash
.venvs/augustus/bin/python -m driversi.rsi.experiments.augustus_campaign evaluate-on-host \
  exp/augustus-navval-full-v1/config.json --execution <execution.json>
```

执行配置单独记录 host、gpus、output、plan_sha256、predecessor_stop_receipt，不改原冻结统计配置。跨节点共用NAS时，先核验原生同输入预测/评分，再停止并确认旧执行及其子进程已退出，最后重分配剩余分片。旧回执及失败尝试保留，已完成分片复用。停止回执只是快照，重试必须重新检查活跃执行。新worker采用独立进程组，失败和中断收回其预处理及评分子进程。

先锁定完整12146个官方navtest场景，32场景一片，按执行配置分配最多8个独立GPU worker。原生4帧历史、prediction CoT、8点轨迹与原生PDMS不变。固定种子42+分片编号；父模型和候选保持同一分片协议，不能称与官方单进程随机流逐位相同。未完成时只显示进度及失败计数，不给正式均分，不允许映射或训练。失败任务不从分母剔除。

全量完成后，将全部零分/低分结果写入私有队列，先用4个有向量的最低分查询各检索8个navval近邻，按源日志分散选择4个训练锚点。缺失向量显式记录。视觉相似不是相同失败原因。navtest token、图像、语言与轨迹不进入训练或派生向量数据库；页面只显示聚合统计。本流程使用测试反馈做开发，后续测试属于自适应评测。

历史实现的对照路线是同锚点重标注（本轮生产已禁用）：从现有DriveTTO候选中选择，经AUGUstus原生PDM重新评分>=95后，替换navval未来轨迹。保留真实历史和原生prediction CoT，不声称生成新图像或新历史。新增数据身份以来源+监督版本确定；独立generated-vectors.sqlite保存历史图像证据、原向量和新训练产物引用，零次新增encoder推理。改变图像的分支不能走复用入口，须重新提取。

普通续训与干预组共享父模型、原样本池和预算，各4次更新+4次续训，另做4次重放核验。之后两个候选都评完整navtest，并复用原父模型完整结果与随机协议。Harness核对恢复、实际正学习率样本曝光、逐项退化并回写实验记忆。一轮8次更新不是稳定提升证据，不自动晋级。

完成批次可恢复；失败预测尝试保留。中断的原生优化阶段不猜测训练状态，必须依据完整检查点选择显式续接或新尝试。工作台复用src/visualization，不发布逐测试场景明细。

当前全量父模型评测继续执行；新历史生产计划尚需完成同分支轨迹、图像及语言监督验收，配对训练与收益尚待实际运行。评测调度器不会因全量完成而绕过这些步骤启动旧重标注训练。工程回归不能替代运行证据；不创建定时聊天跟进。
