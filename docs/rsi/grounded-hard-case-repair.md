# Grounded hard-case repair

Entry: `python -m driversi.rsi.experiments.hard_case_repair CONFIG OUTPUT` declares a task. Register its `task.json` and run it with the existing `driversi.rsi.workflow.engine` in the validated AUGUstus environment. The registered `native_model_hard_case_search` provider owns the bounded loop; no chat agent dispatches individual candidates.

The first pilot selects three existing development TTC failures. It gives Doctor six real first-history/current-anchor images, paired saved plans, and native replay conflict geometry. Replay must reproduce every saved scalar metric and first-infraction time. Object heading and velocity are first-cache measurements, not event-time values. No future sensor image is supplied.

Doctor proposes one text OR applicability edit per attempt. The existing schema prevents executable output, numeric actions, identities, and score-targeting text. Exact effective intervention, close text with the same gate, and unchanged target prompts are rejected before inference. This is lexical/execution deduplication, not a guarantee of distinct causal reasoning. Offline diagnostic future occupancy never enters the student observation; generic conditional wording is required, but syntax checks do not certify semantic grounding.

Up to six requests are permitted. Development targets, all known development regressions and two same-node controls are evaluated with two paired seeds. Native weights, preprocessing, decoder and scoring code stay unchanged. Only a candidate with positive target TTC and mean PDMS improvement and no safety/new-zero regression receives the predeclared cross-log test. One held-out validation is allowed; the search then ends whether it promotes or rolls back. Validation outcomes are excluded from subsequent Doctor context.

The unchanged safety checks compare each scene/seed with both native and incumbent plans. Positive average target TTC means at least one repair, not all three repaired. Promotion is scoped experimental skill state, never a global model release. The selected validation logs have prior experimental exposure; results are retrospective adaptation, not untouched benchmark generalization.

SQLite atomically commits experience and active skill. Completed requests and scoring receipts can be reused; unknown API/inference/scoring outcomes are retained and never blindly replayed. A reply-format error is a recorded rejected attempt and the bounded search continues. Artifacts, plans, image hashes and per-stage costs are saved under `exp/`.

This task does not train, render, rebuild assets, alter existing datasets, or restore public hosting. The separate training-observation analysis checks whether fixed real inputs can use alternative high-scoring future supervision without future RGB.
