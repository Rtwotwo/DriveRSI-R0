# 按来源场景调整生成多样性

本机制服务于现有逐问题纯合成SFT课程。PDMS严格大于0.95、源位姿PSNR严格大于25 dB，以及物理、图像、监督一致性准入均不变。

## 来源证据与技能

`src/rsi/decisions/scene_diversity_skill.py`读取训练caption数据库及`lib/cluster_caption/clusters/`中同一token的真实叶簇。冻结簇编号、词汇、成员哈希、簇速度分布、caption哈希与历轮结果；不读取navtest未来或定位筛选信息。

簇词汇只作为策略提示，不能证明可通行空间、拥堵或原因。测量事实来自来源历史速度、曲率及前方对象间距。每个来源单独计算时间对齐ADE底线、弧长对齐路径差异和速度差异；空间或速度任一满足即可，但全7秒与未来5秒都必须有差异。纯速度变化明确标为速度多样性。相同未来、微小数值抖动不合格。

当前是版本化工程规则：当前速度占85%，有界簇速度先验占15%，再结合曲率、间距、按来源累计的重复比例。动作和参数由Harness生成，不需要逐轮手动改配置。规则的常数与数值防抖下界仍需实验校准，不宣称学到最优策略。反馈范围为本问题此前所有轮次；重复比例的条件分母仅包括教师拒绝、重复拒绝和训练就绪，不包含视觉失败、未知执行或暂缓任务。

旧v1验收回执保持不变。新版本只作用于新轮次；与旧样本进行累计去重时使用新候选自身声明的策略。完整策略必须能从冻结证据重放。

## 先轨迹、后批渲染

主策略配置`scene_diversity.caption_database`后启用来源技能。`resident_postprocessing.collect_before_render=50`将累计已入库数据与待渲染轨迹共同用于调度：先收集至剩余配额，再按来源GS资产分组，每批最多16条、两条GPU后处理通道。

暂存轨迹绝不计作训练数据。图片或监督被拒后继续补足。有限尝试耗尽时处理已积累的尾批，然后由已有恢复控制器调整策略/扩充来源，避免无期限等待50条。最后8次全部失败且至少6次重复时结束该来源本次尝试；教师失败占多数走独立的扰动缩小规则。

同批已完成结果先恢复，不重新渲染。分组改变完成次序，但训练清单始终使用原计划排序。`trajectory-queue.json`报告待渲染数量，`trajectory-family-summary.json`报告最终验收数量；私有平台同时显示动态门槛及两个数量。

## 本次验证范围

单元与集成测试覆盖按同一簇中不同状态计算不同门槛、簇提示与测量事实区别、纯速度变化、相同未来拒绝、固定PDMS防篡改、50条集中收集/不足尾批、跨进程恢复与训练清单顺序一致。真实来源参数见`exp/scene-conditioned-batching-v1/real-source-policies.json`。

测试不等价于实际产量提升或学生收益；须以运行回执、合格数据和后续目标/全量评测分别验证。
