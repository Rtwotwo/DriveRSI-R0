# 逐问题持续学习控制器

当前试点只服务 ChainFlow stage1，复用其9405全量评测的239个零分问题。AUGUstus不能继承这些失败或收益。

入口：`python -m driversi.rsi.experiments.continual_curriculum COMMAND --output exp/continual-scene-curriculum-v1`。
命令顺序为 `initialize → advance → dispatch → train → settle`。`status`只读；`defer`明确暂缓被阻塞的问题。没有后台监控，也不自动无界重启。正在执行或结果未知的任务不能重新分发。

每次只激活一个问题，使用原有无定位视觉Top3、不同来源日志的候选。先从其中一个具备资产的来源生成首批10条不同且合格分支，第二轮目标20条，每个来源最多32次尝试，每问题最多2轮。资产缺失先停止，不把一次尝试当成合格样本。教师、物理、视觉和监督准入保持原样。

两臂从当前已晋级检查点开始，共享完整navtrain普通池及最多32条此前获准样本（FIFO）。合成组增加当前新分支。原生模型、loss及每8个全局样本插入合成样本的采样规则保持不变；两臂优化更新预算相同，调度器数据量参数随实际回放规模扩大。回放不是避免遗忘的保证。

发布条件：当前目标严格改善且PDMS≥0.95；全量12146场景身份齐全；平均PDMS不降低；碰撞、道路、方向、TTC、舒适性逐场景无下降；此前解决案例保持≥0.95；优于普通续训对照且原生observed_pilot_benefit通过；原生训练、真实新增样本暴露与跨进程恢复验证通过。只有全部通过才替换incumbent指针。失败候选和回执保留，旧模型继续有效。

晋级后，已随之改善的排队问题不再重复合成。初始检索池保持冻结，派生回合明确记录其来源与当前父模型，不能宣称重新检索过。新的资产证据需要新版本campaign；当前没有自动补建资产的承诺。

定位使用边界：navtrain自身地图、标定、姿态用于几何及合成；navtest位置/航向仅用于离线审计，不参与筛选。用测试位置改变训练选择属于测试元数据辅助适应，不等于直接复制未来轨迹，但也不是盲测。当前课程已经利用navtest分数反复决策，应报告适应效果；冻结后的独立评测才能支持迁移结论。同位置不证明同交互或标签正确。

可视化配置使用current_only，只投影当前课程、当前问题、当前模型和阻塞状态。历史实验回执留在exp用于追溯，不从常规页面读取或展示。聚类库仍可浏览，去除历史检索实验和对照卡片。公网保持关闭。

早期v1验证曾停在资产门禁。后续资产支持试点已完成真实8更新配对训练及完全一致恢复，现正在恢复其全量评测；新版多轨迹生产与受限GPU配对入口见[轨迹族执行说明](trajectory-family.md)。这仍不等同于已完成连续模型晋级。测试夹具数值不得充当模型收益。

两个训练臂共享回放集合，但不保证回放样本曝光次数相同：固定合成槽位下，治疗臂新样本替代部分回放重复曝光。比较解释为同预算混合数据干预，不能解释成回放曝光完全固定后的纯新增效应。任务按私有token字典序确定，尚未学习排序策略；被拒绝回合的数据保留审计，不计入成功回放。

## 有界自动执行

已授权的自动入口：
```bash
.venv/bin/python -m driversi.rsi.experiments.continual_curriculum auto --output exp/continual-scene-curriculum-v1 --max-problems 3 --max-transitions 18
```

该命令持有课程独占锁，按当前状态顺序调用prepare、dispatch、train、settle。首次最多3个问题、18个阶段；这不是耗时承诺，各原生阶段仍使用自己的已声明预算。每个查询固定3个不同来源日志，不扩大召回池。资产未齐备、未知结果、生成不足时停止；GPU阶段再次检查配置中指定GPU的占用，必须低于500MiB。不会取消其他任务，不会自动换卡、无限等待或重复请求。添加exp课程根目录下的STOP_AUTOMATIC可在阶段之间停止；正在执行的原生阶段继续按自身预算结束。

退出码0表示队列结束、预算用尽或主动停止，须同时查看status；退出码2表示资源/资产/待核验阻塞；异常退出码1。自动记录保存在同一课程automatic目录，当前页面只显示最新状态。没有新增定时监控。资产自动重建后端仍未注册，因此缺资产的任务不会因auto入口存在而自动得到合格GS。
