# 单问题合成 SFT 课程

当前实现：`src/rsi/experiments/continual_curriculum.py`；配置：`src/config/rsi/policies/single-problem-synthetic-sft.json`。

## 当前合同

- 一次处理一个 ChainFlow stage1 零分问题。相关训练来源从既有无定位视觉检索池选择；5是首轮上限，实际个数由相似度差阈值及可用候选决定，不保证5个，也不把该启发式称为检索精度。
- 每个选定来源首轮要求至少10条不同且合格的新数据。未脱离零分时，后续轮扩充到每来源20条，第三轮允许扩大来源范围。当前有限执行最多3轮，未解决时保留未解决状态，需修改策略继续；不会承诺无限增加数据必然学会。
- 合成组只采样该问题的新数据，初始预算完整4遍；记录实际曝光和恢复游标。普通续训组用于对照。原生网络、loss及优化器实现不变。
- 轨迹 PDMS 严格大于95；采用严格27dB数值视觉实验组，源位姿重建PSNR均值严格大于27，轨迹ADE至少0.5m，物理、绑定、来源和同分支监督等既有检查仍执行。
- 27.0与低于27均拒绝。数值准入的源位姿PSNR不是反事实新视角PSNR真值，也不等同于独立人工视觉审核。
- 目标场景PDMS严格大于0记为局部脱离零分；全量平均分、新增零分与安全退化检查另行决定是否晋级。目标仍为0时先回写结果并扩充数据，跳过本轮全量评测。
- navtest反复反馈属于自适应评测。不能把该流程的目标成绩解释为未见测试集泛化。
- 输入与输出按版本冻结，旧25dB凭证不能用于新27dB课程。合成数据沿用dataset中的SimScale式存储，实验回执在exp；navtest明细只留私有记录。
