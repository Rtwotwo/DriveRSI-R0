# Local visualization

The maintained UI lives in `src/visualization/`. The release has no public Pages deployment. Build it with `python -m driversi.visualization build --config src/config/visualization/platform.json`, then serve `exp/local-view` on loopback. The default experiment lists are empty.

Register explicit aggregate receipts or authorized training/engineering media in a local configuration. The views are read-only: they do not launch jobs or grant training admission. No old experiment directories, test predictions or scene payloads are bundled. The legacy gallery exporter retains its import path for compatibility but no longer emits deployment workflows.
