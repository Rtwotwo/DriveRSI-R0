描述原则：
1. 先写驾驶相关空间结构：可见路口/道路弯曲、通行空间、分隔带、路侧停车或建筑出入口。只有图像清楚支持时才称为十字/丁字/合流，不能从一段路缘猜地图拓扑。
2. 写可辨认的标线与控制设施：横道、停止线、车道线、信号灯。标线颜色/实虚/类型不确定时退回“白色路面标记”等上位描述；信号灯存在不代表它控制自车，模糊灯色写未知。
3. 写参与者的配置和潜在视线限制：各相机画面内的近处/远处、靠路边/通行区域、行人/骑行者与车辆的相对位置、占据视野的设施。单张图不能证明车辆停着、行人正在横穿或与自车发生了交互。
4. 写有价值的路侧条件：围栏、施工设施、锥桶、较窄入口、路边车辆影响视野等。不要用品牌、车牌、招牌文字、建筑装饰或猜测的天气凑字数。
5. 当前帧不能证明过去/未来的切入、变道、让行、加减速及事故原因。导航指令是意图而非实际动作；当前速度是测量值，不是速度变化。
6. 每项事实引用正确的image_id；左右优先写成“前/左/右/后视图的画面左侧”等，避免把相机画面方向误当全局/自车坐标。跨相机对象身份未匹配，不合计对象总数。
7. 不确定项独立列出，别让不确定细分类进入确定的检索标签。描述同一对象在不同相机中的信息时不要声称是同一个对象。
